# 02 · Editable Sources

**Status:** WP2 signal generator and dashboard sources are available; remaining
production files are not started.

The project includes `wp2_signal_generator.py` and the interactive dashboard
source in `artifacts/heatguard/`. The signal generator recreates the WP2 charts,
video overlays, static diagram, animated signal-flow SVG, sample CSV, and
assumption manifest; see
`05_Technical_Assets/README.md` for the output location and command. Add the
editable 3D scene, video-editor timeline, narration, and other source assets
here as they are created.

Do not treat generated plots as site measurements or test evidence.
